# Descripción
```<espe-theme-toggle>``` Es un componente web personalizado desarrollado con LitElement, que permite alternar entre el modo claro y oscuro en una aplicación web, respetando la identidad visual institucional de la Universidad de las Fuerzas Armadas ESPE.

Incluye soporte para estados reactivos, animaciones suaves, accesibilidad y comunicación entre componentes mediante eventos personalizados.
